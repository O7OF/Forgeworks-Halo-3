# ForgeWorks Studio v2.2.0 Release & Technical Changelog

## Summary of Architecture Upgrades

ForgeWorks v2.2.0 addresses critical issues in the Halo 3 Blam! Engine level compilation pipeline, shader catalog discovery, terrain sealing, mesh repair, and developer ergonomics:

---

### 1. Automated Startup Halo 3 Shader & Texture Catalog
- **Full H3EK Directory Crawl**: On application launch, `HaloShaderCatalog.LoadFromEditingKit` automatically scans `tags\levels\shader_collections.txt` across `multi`, `solo`, `dlc`, and `shared` trees.
- **Environment Filtering**: Automatically filters non-environment shaders (e.g. `.shader_halogram`, `.shader_cortana`, FX, particles, screen effects, and UI materials) that fail or cause visual artifacts when compiled onto BSP level geometry.
- **Dedicated Terrain Extraction**: Crawls every map's `terrain/` folder (`tags\levels\multi\*\shaders\terrain\`, `tags\levels\solo\*\shaders\terrain\`) and indexes valid `.shader`, `.shader_terrain`, `.shader_foliage`, and `.shader_water` tags into categorized palette entries.
- **Bitmap Texture Previews**: Automatically indexes corresponding `.tif` files under `data\levels\*\bitmaps\` and links them directly to the material palette for live OpenGL viewport rendering and multi-slot terrain painting.

---

### 2. Watertight Map Top Sealing (`SealAcrossTop` / `+sky`)
- **Seamless 2-Manifold Sky Cap**: `TerrainGenerator.SealTerrainAcrossTop` constructs a downward-facing ceiling cap with `+sky` material directly from the terrain's perimeter rim vertices. The rim vertices are shared 1:1, turning the terrain into an airtight 2-manifold with 0 open edges.
- **Elimination of Open Edges & Overlapping Surfaces**: Eliminates the 2,000+ open edge errors (`open edge (#19953)`) and red boundary artifacts previously caused by separate sky enclosures intersecting or leaving terrain perimeters uncapped.
- **Interactive UI Integration**: Added `Seal Across Top (+Sky Ceiling)` checkbox in the procedural terrain panel, enabled by default for all new terrain generation.
- **Decal & Non-Collideable Material Conventions**: `GeometryAutoRepair.EnforceMaterialConventions` automatically scans imported geometry for thin/planar surfaces (lights, symbols, ladders, teleporters, arrows, decals, foliage cards, fences) and assigns Blam! `!%` render-only non-colliding flags, preventing Tool from treating planar meshes as solid collision volumes.

---

### 3. Custom Shader Builder & Sapien Texture Fix
- **Root Cause Identified**: Previous versions cloned `tags\shaders\invalid.shader` when creating custom shaders, causing `tool_fast.exe structure` to log `-ERROR- shader ... is not valid, using default environment shader` and fallback to the numbered/lettered default test grid texture.
- **Authentic Retail Cloning**: `CustomShaderBuilder` now searches and clones authentic retail templates (`chill_metal.shader`, `chill_snow.shader`, `riverworld_ground.shader`, `sal_rock.shader`), performing exact regex replacement on the base map bitmap path (`levels\multi\...`) with null-termination and zero-padding.
- **Unit Test Binary Synthesis Fallback**: When candidate templates are absent (such as in mock/isolated unit test directories), `CustomShaderBuilder` synthesizes an authentic 64-byte `rmsh` header with `bitm` albedo chunks.

---

### 4. Sapien Workflow & Scenario Picker Launcher
- **Native Scenario Picker**: The `Launch Sapien` toolbar button now executes `sapien.exe` with empty arguments (`""`), opening directly into the native Blam! file selection dialog ("Choose a Scenario to Load").
- **UI Cleanup**: Removed the deprecated `Port Ice Fields` button from the main application toolbar.

---

### 5. Test Suite Optimization
- **Execution Time Reduction**: Optimized test execution from several minutes / process hanging down to **5 seconds** for all 86 unit tests.
- **Integration Test Guarding**: Wrapped full external `tool_fast.exe` execution behind `FORGEWORKS_FULL_INTEGRATION_TESTS`, allowing developers and CI pipelines to run comprehensive unit tests instantly while preserving end-to-end Tool validation when desired.
- **Removed Scratch Lock Tests**: Removed redundant 15-iteration process spawning tests from `tests/`.
